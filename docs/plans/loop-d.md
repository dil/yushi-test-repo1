# Plan: loop-d

Context: exercise the subagent-driven-development loop over many small,
independent tasks. Each task adds exactly one new file at the repo root
containing exactly one line of text. No task touches another task's file.

Global Constraints:
- Each task creates exactly one file, `D-NN.md`, at the repository root.
- The file's sole line of content is `Task D-NN`, where `NN` is the task's
  two-digit number (e.g. `D-01.md` contains the line `Task D-01`).
- Each task is committed on its own, with a commit message naming the task
  (e.g. `Add D-01.md`).
- No task modifies a file created by another task.
